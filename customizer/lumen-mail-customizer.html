Lumen mail customizer

Pick a preset, change colours, type, shape, logos and CSS, check the preview and download a customization ZIP for the Lumen skin of Roundcube Webmail. Everything happens in this page; nothing is uploaded. Token files are the same as for the other Lumen themes.

Start

Colours (light)

Each mode has its own palette. Switch the preview to edit the other one. The task rail and the login page use the dark palette in both modes.

    Typography

    Sora ships with the skin. Other fonts must be installed on the visitor's device, or uploaded under Branding and loaded with @font-face in custom CSS.

    Shape, spacing and layout
    Values only other Lumen themes use

    Roundcube keeps its own column layout and switches dark mode per user, so these are kept in the token file for the panel and browser themes but change nothing here.

    Branding

    PNG, JPEG, WebP, GIF, ICO or SVG up to 4 MB, kept in this page and added to the ZIP. Roundcube serves skin files only, so upload logos instead of linking them. The logo sits on the dark task rail and login page: the dark-mode logo is used, or the light one when there is none. SVG files with scripts, event handlers or outside references are refused (the server checks again).

    Custom CSS

    Added after the skin's stylesheet. Use the variables (var(--lm-surface), var(--lumen-accent)) so rules follow both modes; dark mode is html.dark-mode. Uploaded files are url("/storage/lumen/<file>").

    Files

    Install the ZIP on the Roundcube server with lumen-mail apply-custom <zip> --roundcube /var/www/roundcube (a dry run; add --yes). The skin is then compiled there from the installed Elastic. The ZIP holds only the compiled LESS and CSS overrides, the token file and your uploads.

    lumen-mail 0.1.2 customizer, a Luminare Development open-source project (MIT). The preview is a mock with example data, written for this page (no Roundcube or Elastic file); the Sora font (SIL OFL 1.1) is embedded for it. lumen-mail is not affiliated with or endorsed by the Roundcube project.

    Import

    Paste a Lumen token JSON (an export of any Lumen theme works), or choose a token file or a ZIP made here.
